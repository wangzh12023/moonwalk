Install

# with the MoonBit toolchain (and a C compiler; MSVC on Windows)
moon install https://github.com/wangzh12023/moonwalk.git cmd/moonwalk --branch main

# inside any MoonBit module
moonwalk why                          # explain the failing check
moonwalk record TEST --html run.html  # write a viewer like the ones above
moonwalk mcp                          # serve the history to AI coding agents

What it does

  • Record once, explore forever. Every statement, call, argument, return value, branch and assignment of the test is recorded. You can step forwards and backwards, step over and out, and jump to any moment.
  • Ask why. MoonWalk computes the dynamic slice of a value: the assignment that produced it, the variables and calls it depended on, and the decisions that made it happen, across function boundaries.
  • No setup. It works on any MoonBit module without changing it. It instruments a shadow copy of the source, so it needs no compiler plug-in and no debug symbols. It runs on every backend moon test supports.
  • For people and for AI agents. It has a terminal transcript, these standalone viewers, and an MCP server so Claude Code, Cursor or Codex can query the execution instead of guessing.
  • Written in MoonBit. The instrumenter uses the official parser. The trace engine, the CLI, the MCP server and this viewer (with rabbita) are MoonBit, and the viewer runs the same why engine compiled to JavaScript.
